# stock-market-prediction
Stock Market Prediction using LSTM with historical data collected from Yahoo Finance. The project analyzes stock price trends, preprocesses time-series data, and predicts future prices using an LSTM model. An interactive Streamlit dashboard provides data visualization and prediction results.
